# 📋 ToDoListBot

Личный Telegram-бот для управления задачами. Помогает планировать дела, расставлять приоритеты и не пропускать дедлайны — бот напомнит сам.

---

## ✨ Возможности

- ✅ Добавление задач с названием, приоритетом и дедлайном
- 📋 Просмотр всех активных задач
- 🔔 Автоматические напоминания за выбранное количество часов до дедлайна
- ✔️ Отметка задачи как выполненной
- 🗑 Удаление задач из списка

---

## 🤖 Команды

| Команда | Описание |
|--------|----------|
| `/start` | Запустить бота |
| `/add` | Добавить новую задачу |
| `/list` | Показать все задачи |
| `/done <id>` | Отметить задачу выполненной |
| `/delete <id>` | Удалить задачу |
| `/help` | Показать справку |

## 🚀 Запуск локально

**1. Клонируй репозиторий**
```bash
git clone https://github.com/ogyrchik289/ToDoListBot.git
cd ToDoListBot
```

**2. Создай виртуальное окружение**
```bash
python -m venv .venv
.venv\Scripts\activate  # Windows
source .venv/bin/activate  # Linux/Mac
```

**3. Установи зависимости**
```bash
pip install -r requirements.txt
```

**4. Создай файл `.env`**
```
TOKEN=твой_токен_от_BotFather
```

**5. Запусти бота**
```bash
python bot.py
```
